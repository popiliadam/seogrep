title: SeoGrep Docs
description: What SeoGrep is and how to get value from it in your first session.
---

SeoGrep is a hosted MCP server for SEO analysis. You add your personal MCP URL
to the AI client you already use — Claude Desktop, claude.ai, Claude Code,
Cursor, or Windsurf — and run crawls, audits, and Search Console analysis by
asking in plain language. Credits pay for analysis work; your AI subscription
stays your own.

> **Beta note:** SeoGrep is in beta. Some details below may still change as
> the service evolves.
