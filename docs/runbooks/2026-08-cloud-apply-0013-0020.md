## §A — 0017 APPLY'DAN ÖNCE: ihlal sayımı

Salt-okunur. **Beklenen: üç satır, hepsi `0`.** Sıfırdan farklı bir sayı varsa **APPLY ETMEYİN.**

```sql
select 'jobs->projects' as edge, count(*) as violations
  from public.jobs j left join public.projects p on p.id = j.project_id
  where j.project_id is not null and (p.id is null or p.user_id <> j.user_id)
union all
select 'gsc_connections->projects', count(*)
  from public.gsc_connections g left join public.projects p on p.id = g.project_id
  where g.project_id is not null and (p.id is null or p.user_id <> g.user_id)
union all
select 'reports->jobs', count(*)
  from public.reports r left join public.jobs j on j.id = r.job_id
  where r.job_id is not null and (j.id is null or j.user_id <> r.user_id);
```

Sıfırdan farklı bir satır çıkarsa: bu, 0017'nin önlemek için var olduğu **çapraz-kiracı bug'ının
kanıtıdır**. Parent pointer'ı öylece NULL'lamayın — önce satırın gerçek sahibi (`user_id`)
belirlenmeli. Bu noktada durun ve şefe rapor edin.

## §B — 0016 APPLY'DAN SONRA: kalıntı taraması

**Neden zorunlu:** hakem deneyle kanıtladı — **başka bir grantor'un verdiği TRUNCATE, 0016'nın
revoke'undan SESSİZCE sağ çıkar** (hiçbir uyarı yok). Üç sorgunun üçü de **0 satır** dönmeli.

**B1 — herhangi bir app rolünde kalan TRUNCATE (davranışsal kontrol):**

```sql
select c.relname as tbl, roles.rolname
from pg_class c
join pg_namespace n on n.oid = c.relnamespace
cross join (values ('anon'),('authenticated'),('service_role')) as roles(rolname)
where n.nspname = 'public' and c.relkind = 'r'
  and has_table_privilege(roles.rolname, c.oid, 'TRUNCATE')
order by 1, 2;
```

**B2 — farklı-grantor kalıntısı (ACL'e doğrudan bakar; B1'in kaçırabileceği şekil):**

```sql
select c.relname as tbl,
       a.grantor::regrole as granted_by,
       a.grantee::regrole as granted_to
from pg_class c
join pg_namespace n on n.oid = c.relnamespace
cross join lateral aclexplode(c.relacl) a
where n.nspname = 'public' and c.relkind = 'r'
  and a.privilege_type = 'TRUNCATE'
  and a.grantee::regrole::text in ('anon','authenticated','service_role')
order by 1;
```

Satır çıkarsa tedavi, **grantor'u açıkça belirterek** revoke etmektir:

```sql
revoke truncate on table public.<tbl> from <granted_to> granted by <granted_by>;
```

> **Eskalasyon:** `granted_by` = `supabase_admin` ise Supabase SQL Editor yetmeyebilir.
> O noktada durun — bu bir destek/eskalasyon kalemidir, zorlamayın.

**B3 — default ACL'de kalan TRUNCATE biti (yeni doğacak tablolar için):**

```sql
select d.defaclrole::regrole as owner, n.nspname as schema, d.defaclacl
from pg_default_acl d
left join pg_namespace n on n.oid = d.defaclnamespace
where d.defaclobjtype = 'r'
  and array_to_string(d.defaclacl, ',') like '%D%';
```

(`D`, aclitem gösteriminde TRUNCATE'tir.) Satır çıkarsa **yeni tablolar TRUNCATE grant'iyle doğar**
ve 0016'nın geleceği koruma yarısı delinmiştir.
